Test requests to the real gateway

Sends the request above (the port of its preset) to the gateway URL the given number of times and counts which pool answered. It keeps 6 requests open at a time and sends the next one as each finishes. The results appear under "Real response", with the total time and the average response time per pool.

Before you test priority-based selection on the real gateway, stop pool-canary on VM 2 by hand. Otherwise every request keeps going to Primary (VM 2, priority 1) and you cannot see the switch to Standby (VM 1).

Stop (Azure CLI):

az vm run-command invoke -g rg-agw-advrouting-demo -n agwdemo-backend-canary --command-id RunShellScript --scripts "systemctl stop agw-pool@pool-canary"

Restore (run it after the test; requests then go to Primary (VM 2) again):

az vm run-command invoke -g rg-agw-advrouting-demo -n agwdemo-backend-canary --command-id RunShellScript --scripts "systemctl start agw-pool@pool-canary"
